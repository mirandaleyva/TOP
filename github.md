# ¿Qué es GitHub?

GitHub es una plataforma que admite todo el proceso de desarrollo de software, desde el trabajo de planificación hasta la implementación y el software operativo.

GitHub es una plataforma para compilar software. Tanto si va a iniciar un nuevo proyecto como si contribuye a uno existente, GitHub reúne las herramientas y los flujos de trabajo que necesita en todas las fases del ciclo de vida de desarrollo de software (SDLC).

## GitHub y el ciclo de vida del desarrollo de software

El ciclo de vida de desarrollo de software describe las fases en las que un proyecto de software pasa, desde la primera idea hasta la ejecución de código en producción.
GitHub está diseñado para respaldar todas las fases de ese proceso.

| Stage   | Lo que puedes hacer en GitHub                                                                                                      |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Plan    | Realice un seguimiento del trabajo, establezca hitos y organice proyectos a largo plazo.                                           |
| Create  | Escribir y almacenar código, desarrollar nuevas características de forma segura y crear una escala de tiempo clara de los cambios. |
| Review  | Sugerir cambios en el proyecto, analizar las actualizaciones con los revisores y aplicar comentarios.                              |
| Test    | Automatice las comprobaciones para validar todos los cambios antes de combinarlos.                                                 |
| Deploy  | Envíe software con flujos de trabajo de implementación automatizados y administración de versiones.                                |
| Operate | Supervise las aplicaciones, administre las dependencias y busque y corrija problemas de seguridad.                                 |

No es necesario usar cada fase a la vez. Muchas personas comienzan con un repositorio y algunos problemas y, a continuación, expanden su uso de la plataforma a medida que crece su proyecto.

## GitHub y Git

GitHub se basa en el software de código abierto, Git.

Git es un sistema de control de versiones que realiza un seguimiento de los cambios en los archivos. Le permite trabajar en su propia copia de un proyecto, registrar un historial de los cambios y combinar su trabajo con los cambios de otras personas de forma segura.

GitHub se basa en Git mediante el hospedaje de los proyectos de Git, **denominados repositorios**, en la nube, así como la adición de herramientas de planeación y colaboración que facilitan a los equipos trabajar juntos.

Para más información sobre Git, consulte [Acerca de Git](/es/get-started/using-git/about-git).

## ¿Es GitHub adecuado para mí?

GitHub los usan estudiantes, desarrolladores, administradores de proyectos, equipos de seguridad, científicos de datos, investigadores, recursos humanos y personal legal, y muchos otros en organizaciones de todos los tamaños.

Algunas de las razones más comunes por las que la gente usa GitHub son:

- Almacenar y administrar código con control de versiones.
- Escriba código, revise el código, administre las vulnerabilidades de seguridad y las actualizaciones.
- Colabore y socialice en proyectos.
- Contribuir al software de código abierto.
- Realizar un seguimiento y administrar proyectos.
- Automatice flujos de trabajo de desarrollo de software como CI/CD, pruebas e implementaciones.
- Presentar y compartir trabajo.
- Publicar y liberar paquetes de software.
- Aloje documentación y sitios web.
- Participar en las comunidades de desarrollo de software y discusiones.
- Use herramientas y agentes con tecnología de inteligencia artificial para ayudar a escribir, comprender, revisar y automatizar el desarrollo de código más rápido.

## ¿Dónde empiezo?

Si es la primera vez que usa GitHub y no está familiarizado con Git, le recomendamos consultar los artículos de la categoría [Póngase en marcha](/es/get-started/start-your-journey). En los artículos se muestra cómo realizar tareas comunes que los desarrolladores de software realizan mediante GitHub, como:

- **Cree un repositorio para el proyecto de software** y almacene el código en GitHub, consulte [Creación de un repositorio para el proyecto en GitHub](/es/get-started/start-your-journey/creating-a-repository-for-your-project-on-github).
- **Planee el trabajo** mediante la creación de problemas y el seguimiento del trabajo del proyecto.
- **Conéctese al código en el equipo local** y use la GitHub Desktop aplicación para administrar los cambios de código con Git.
- **Escriba y almacene el código**, si lo desea, empareje con un asistente de IA y sincronice los cambios con GitHub.
- **Revisa los cambios de código propuestos** creando solicitudes de extracción y revisando tus propios cambios antes de fusionarlos.
- **Implemente el sitio web** mediante flujos de trabajo de implementación automatizados, lo que le permite publicar un sitio web básico para su proyecto de software.
